# 模型推导：差速底盘 Frenet 误差 与 线性时变 MPC

> 本文件是 `mpc_core`（Python 参考核心）与 `include/linear_mpc_controller`（C++ 实时核心）
> 的唯一数学权威（R1/R2/R25）。所有符号约定在此冻结，代码与测试必须一致。

## 1. 符号与约定（冻结）

世界系采用 ROS 约定：`x` 前、`y` 左、`yaw` 逆时针为正。

- 参考轨迹点：`(s, x, y, yaw, κ, v)`，`s` 为累计弧长，`yaw` 为该点切线方向，
  `κ = d(yaw)/ds`（**κ > 0 表示左转/逆时针弯**），`v ≥ 0` 参考前进速度。
- Frenet 参考系固连在参考路径上：
  - `e_y`：有符号横向误差，机器人位于参考切线行进方向**左侧为正**；
    （对 κ>0 的弯道，圆心在左侧，因此 `e_y` 指向圆心一侧；`e_y<0` = 弯道外侧）
  - `e_ψ = wrap(ψ − ψ_ref) ∈ [−π, π)`：航向误差；
  - `v, ω`：机器人**绝对**线/角速度（来自 `/odom`）。
- MPC 状态（冻结）：`x = [e_y, e_ψ, v, ω] ∈ R⁴`；决策（冻结）：
  `u = [a, α]`（线加速度 m/s²、角加速度 rad/s²，控制周期内 ZOH 保持）。
- 控制周期 `Ts = 0.05 s`（20 Hz），预测时域 `N`（步）。

### 1.1 局部坐标系几何

记参考点位置 `r_p(s)`、左侧法向 `n̂(s)`（切线 `t̂` 逆时针转 90°）。
Serret–Frenet：`t̂′ = κ n̂`、`n̂′ = −κ t̂`（对 κ>0 左转一致）。

机器人位置 `r = r_p + e_y n̂`，速度为 `v(cos e_ψ t̂ + sin e_ψ n̂)`，投影点弧速 `ṡ`。
对时间求导并投影到 `(t̂, n̂)`：

```
ṡ(1 − κ e_y) = v cos e_ψ            (切线分量)
ė_y          = v sin e_ψ            (法向分量)
ė_ψ          = ω − κ v cos e_ψ / (1 − κ e_y)   (航向：减去参考切线转动 κṡ)
v̇ = a,  ω̇ = α                      (积分器假设)
```

> 说明：`ė_y = v sin e_ψ` 与 `ṡ` 无关（精确）；`ė_ψ` 中的 `κv cos e_ψ/(1−κ e_y)`
> 是“路径曲率导致的参考切线转动”，是线性 MPC 在弯道上产生二阶失配的根源
> （见 §5 精度讨论）。

## 2. 在参考点线性化（LTV）

在工作点 `(e_y, e_ψ, v, ω) = (0, 0, v_r, κ v_r)` 线性化（`v_r, κ` 取当前锚点，逐段常数）：

```
A_c = [ 0      v_r      0    0 ]
      [ −κ²v_r   0      −κ    1 ]
      [ 0       0       0    0 ]
      [ 0       0       0    0 ]

B_c = [ 0  0 ]
      [ 0  0 ]
      [ 1  0 ]        (a → v̇)
      [ 0  1 ]        (α → ω̇)

仿射项 g = 0（工作点本身是平衡点：ω* = κ v_r 时 ė_ψ = 0）
```

验证要点（有单测 `test_linearization_matches_numeric_jacobian`）：
- `∂ė_y/∂e_ψ = v cos e_ψ |₀ = v_r`；
- `∂ė_ψ/∂e_y = −κ v cos e_ψ · (κ)/(1−κ e_y)² |₀ = −κ²v_r`（符号与“左侧为正”约定一致）；
- `∂ė_ψ/∂v = −κ cos e_ψ/(1−κ e_y) |₀ = −κ`；
- `∂ė_ψ/∂ω = 1`。

## 3. 离散化（ZOH）

对每个预测步 `j`，用该步锚点的 `(v_r,j, κ_j)` 生成 `(A_c,j, B_c,j)`，再做 ZOH：

```
[A_d, B_d] = expm([[A_c, B_c], [0, 0]] · Ts) 的左上分块
```

Python 参考核心用自带的稠密 `expm`（缩放-平方 + Taylor，无第三方依赖）；
C++ 核心在 WSL2 用 Eigen 的矩阵指数或等效实现，二者离散误差在同一数量级
（单测用高步数线性积分验证：ZOH 误差 < Euler 误差，且 < 1e-4 量级）。

**冻结默认离散方法：ZOH**。Euler 保留在代码中仅用于误差对比（C1 验收项）。

## 4. Condensed 二次规划（U3）

### 4.1 预测

记堆叠预测状态 `X = [x₁; …; x_N] ∈ R^{4N}`，堆叠决策 `U = [u₀; …; u_{N−1}] ∈ R^{2N}`：

```
X = F x₀ + G U
F:  (4N×4)  递归 F[k] = A_d,k F[k−1]
G:  (4N×2N) 块列 j 对 k≥j：Φ(k, j+1) B_d,j   (Φ 为状态转移积)
```

### 4.2 代价

```
J(U) = Σ_{k=1..N} (x_k − x_ref,k)ᵀ Q_k (x_k − x_ref,k)
     + Σ_{j=0..N−1} u_jᵀ S u_j
     + (x_N − x_ref,N)ᵀ Q_F (x_N − x_ref,N)
```

- `x_ref,k = [0, 0, v_r(s_k), κ(s_k) v_r(s_k)]`，参考点在预测弧 `s_k`（按参考速度推进）。
- `Q = diag(Q_diag)` 作用于误差状态；终端 `Q_F`。
- 展开为 `min ½ Uᵀ H U + qᵀ U`：`H = Gᵀ Q̄ G + S̄`，`q = Gᵀ Q̄ (F x₀ − X_ref)`。

### 4.3 约束（MVP，硬约束）

| 约束 | 形式 | 行数 |
|---|---|---|
| 速度 | `v_min ≤ v_k ≤ v_max`（每预测步） | 2N |
| 角速度 | `|ω_k| ≤ ω_max` | 2N |
| 线加速度 | `|a_j| ≤ a_max` | 2N |
| 角加速度 | `|α_j| ≤ α_max` | 2N |

均写成 `l ≤ C U ≤ u`（状态约束经 `x_k = F_k x₀ + G_k U` 平移；输入约束直接 box）。
软约束放宽（速度 slack）与不可行分级降级为 C2/后续单元；MVP 用硬约束 + 回退梯子。

### 4.4 求解器契约（C++ OSQP 与 Python ADMM 一致）

`min ½zᵀPz+qᵀz s.t. l ≤ Az ≤ u`：
- `setup`（结构固定）→ 每周期 `updateGradient / updateBounds` → `solve`；
- 输出 `status (SOLVED / APPROXIMATE / FAILED)`、迭代数、primal/dual 残差、耗时；
- warm start：上一周期解**平移**（丢弃首块、末尾补 0），失败则清零（防止把坏 ADMM 状态喂回）。

### 4.5 控制输出（冻结）

```
cmd_vel 候选 = [ v + Ts·a₀ ,  ω + Ts·α₀ ]     (第一个预测状态的 v/ω)
```

### 4.6 回退梯子（R4/R13，冻结）

健康状态：`OK / NO_REFERENCE / STALE_REFERENCE / TF_INVALID / STATE_STALE /
QP_TIMEOUT / QP_INFEASIBLE / NAN_OUTPUT / SAFETY_CLAMPED / FALLBACK_ACTIVE / EMERGENCY_STOP`

1. 关键状态（无参考/参考过期/TF 无效/状态冻结/NaN/急停）→ **立即输出 0**，禁止沿用上一帧非零控制；
2. QP 失败（超时/不可行）→ 确定性子降速：`v ← v·(1 − decel·Ts/v)` 几何衰减，航向保持 0；
   超过 `max_hold_cycles` 仍未恢复 → `EMERGENCY_STOP`；
3. 健康解 → 硬边界限幅（超界记 `SAFETY_CLAMPED`）。

## 5. 精度讨论与已知边界（诚实记录）

- 稳态圆弧跟踪：线性化把 `1/(1−κe_y)` 截断到一阶。参考核心无前视（`lookahead=0`）时，
  R=2 m 圆、v=0.5 m/s 实测 `e_y_rms ≈ 0.01 m`；引入前视锚点会带来“切弯”稳态内侧偏移
  （0.1 m 前视 ≈ 0.04 m 偏移），因此 **MVP 默认前视为 0**，延迟补偿留给 C5 系统辨识。
- 大初始误差恢复受 `a_max/α_max` 限制：直线横向 0.6 m、航向 0.25 rad 起步，
  恢复期 RMS ~0.12–0.24 m（物理可达性的真实代价，不是调参能消除的）。
- 模型失配来源（后续 RL 残差的设计目标）：轮径/轮距误差、`cmd_vel → 实际速度` 的一阶滞后、
  控制延迟、噪声——见 `docs/ros2_interface_contract.md` 与 C5。

## 6. 指标定义（R22）

- `e_y`：实际轨迹点到参考轨迹的**有符号** Frenet 横向距离（约定见 §1）；
- `e_ψ`：归一化 `[−π, π)` 的角度差；
- `e_v = v − v_ref`；
- `J_smooth = mean ‖u_t − u_{t−1}‖²`；
- 求解器：mean / p95 / max 耗时、超时率、不可行率、迭代数；
- 每 run 记录：参考/实际轨迹、控制、健康状态、QP 耗时、约束违反、种子、配置哈希。
